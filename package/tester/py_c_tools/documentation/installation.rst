Installation
------------

Installation of the package goes as follows:

1. Clone the package from `here <http://rdegitlab.gorenje.si/testing/py_c_tools>`_
2. Inside root directory run ``pip install .`` to install package. It will also install all requirements.

To build documentation use:

1. ``pip install -r requirements_docs.txt`` to install documentation generation dependencies
2. ``python setup.py build_doc -a`` to build documentation.
